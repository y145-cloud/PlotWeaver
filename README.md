# 伏笔导演 Plot Weaver

> 给酒馆加一个「长期导演」：写下**未来一定要发生的剧情点**或**整段大纲**，
> 扩展会在接下来几十到上百楼里按进度自动、逐步地把 AI 往那个方向推，
> 而不是下一楼就把它写完。

支持 **SillyTavern** 与 **TauriTavern（TT，Tauri 桌面版）**，纯前端扩展，不需要任何后端 / Node 插件。

Let the model *foreshadow* a future story beat over dozens or hundreds of messages instead of resolving it on the next turn.

---

## 它解决什么问题

- 你在标签里写「最后主角要背叛师父」，AI 下一段就安排背叛 —— 这一楼就写完了。
- 你想要的是：第 20 楼埋犹豫，第 50 楼埋误会，第 80 楼才真正爆发。

本扩展给每个剧情点设定一个**目标楼**，然后按「已走 / 总跨度」自动换阶段（默认走「缓慢」曲线：前 1/3 都还在起念期，越往后才越明显）：

| 阶段 | 位置 | 对 AI 的要求 |
| --- | --- | --- |
| 起念期 | 0–15% | 只允许可被忽略的痕迹（环境、旧物、闲话、记忆），**禁止点名事件**；多数楼层可以不提 |
| 酝酿期 | 15–45% | 允许更具体的痕迹（一段记忆、别人一句评价、一个对不上的细节）；不要求出现 |
| 浮现期 | 45–75% | 相关的人或事可以出现，但**只按场景本身的逻辑**：本来在场、被正常理由叫来 |
| 临门期 | 75–95% | 可以被人物隐约察觉（不安、怀疑、追问），怎么处理仍由场景决定 |
| 触发期 | ≥95% | 让事件发生，用已有细节接上 |
| 逾期收束 | 超过目标楼 | 本楼让它发生 |

每楼注入的指令都会带上「当前第 X 楼 / 目标第 Y 楼 / 当前阶段」，
外加一句硬约束：**与它无关的楼层是常态，可以连续多楼完全不提它；相关角色不因为“该铺垫了”而登场**。

## 为什么不受「只对最近四楼生效的正则」影响

你那个正则大概是「深度 0–3」之类，只改最后几条消息，所以效果会随楼层滑走。

本扩展**完全不改消息文本**：

1. 进度和目标写在**当前聊天的元数据**（`chat_metadata`）里，跟着聊天存档；
2. 每一楼生成前，重新拼一段**新的**注入内容（楼层、阶段都在变），
   用 `setExtensionPrompt` 放进提示词的指定深度；
3. 所以它只依赖「每次生成都会重新注入」，不依赖任何消息留在上下文里，
   撑一百楼、刷新页面、重开酒馆都还在。

## 安装

### SillyTavern

1. 把整个 `PlotWeaver` 文件夹放到
   `SillyTavern/public/scripts/extensions/third-party/PlotWeaver/`
   （目录里应直接看到 `manifest.json`、`index.js`、`settings.html`、`style.css`）。
2. 刷新页面（F5）。
3. 打开「扩展」面板 → 找到 **伏笔导演**。

> 用 zip 安装时不要多套一层目录：`third-party/PlotWeaver/manifest.json` 才对。

### TauriTavern（TT）

二选一：

- **图形界面安装（推荐）**：扩展抽屉 →「安装扩展」，填本仓库地址
  `https://github.com/y145-cloud/PlotWeaver`，可勾选「为所有用户安装」（global）。
- **手动放置**：
  - 仅当前用户：`<数据目录>/default-user/extensions/PlotWeaver/`
  - 全局：`<数据目录>/extensions/third-party/PlotWeaver/`
  - Windows 默认数据目录：`%APPDATA%/com.tauritavern.client/data`
  - 两处同名时 **local 优先**。
- 放好后重启 TT，或在「管理扩展」面板里刷新一次。

TT 侧使用与 ST 完全相同的扩展契约（`manifest.json` + `js`/`css`，通过
`/scripts/extensions/third-party/PlotWeaver/` 加载），因此功能一致：

- 设置面板、悬浮进度条、斜杠命令、JSON 导入导出全部可用；
- 注入走 TT 的 `setExtensionPrompt`，同样每楼重算，不受聊天虚拟化影响
  （本扩展不碰消息 DOM）；
- TT 会在渲染设置模板时额外做一次 DOMPurify 清洗，若模板渲染器不可用，
  本扩展会自动退回直接抓取 `settings.html`，保证面板一定出得来。

## 用法

### 0. 魔棒快捷入口

聊天输入框上的**魔棒按钮**（🪄）菜单里多了一项「**伏笔导演**」，点一下弹出快捷面板：

- 上面直接显示当前目标的阶段、剩余楼数与进度条；
- 下面可以直接写一个新剧情点（标题 / 目标楼 / 关键词 / 说明）并「加为目标」，不用先进设置；
- 「打开完整设置」会展开左侧扩展设置抽屉并滚动到本插件面板；
- 点遮罩、右上角 ✕ 或按 Esc 关闭。

快捷面板只是入口，状态和完整面板共用同一份数据，改哪边都一样。

### 1. 加一个剧情点

扩展面板 →「添加剧情目标」：

- **标题**：一句话，例：`主角发现父亲的秘密`
- **具体说明**：会逐字交给 AI，越具体越好
- **目标楼**：留空则默认「当前楼 + 40」（可在设置里改默认跨度）。
  输入框下面会实时显示**当前楼层**和这一行的意思，例：`当前楼层：2`、`第 22 楼 = 大约 20 楼后`；
  懒得算就点快捷按钮 **当前+10 / +20 / +40 / 就是现在**，直接填好。魔棒快捷弹窗里也有同样一行。
- **关键词**：逗号分隔，例 `日记,地下室,旧案`。用来扫描 AI 已经写出的相关片段（自动记录成「已埋伏笔」），
  以及「疑似提前触发」提醒
- **必须包含 / 禁止事项**：一行一条，会原样注入
- **已铺垫记录**：作者手记，注入时提醒 AI 保持一致

### 2. 大纲导入

把大纲一行一个剧情点粘进去，设置「间隔楼数」，点「按大纲生成目标」。
例：5 行 + 间隔 25 楼 = 从现在起第 25/50/75/100/125 楼依次发生。

生成后同一时间只有一个「当前目标」被重点注入，后面的只会给一句模糊提示
（可在设置里关掉），避免 AI 提前把后面的也写了。

### 3. 随时调整

当前目标卡片上有：**立即触发**（把目标改成下一楼）、**提前 10 楼**、**延后 10 楼**、**已完成**。

「全部目标」里每个目标还能：设为当前 / 暂停 / 恢复 / 编辑 / 完成 / 归档（归档不删除，可恢复）。

**删除**：每个目标卡片（含已归档的）都有「删除」按钮，点第一次会变成「再点一次删除」，
4 秒内再点一次才真正删除，防手滑；超过 4 秒自动还原。删掉当前目标后，会自动把剩余目标里
楼层最近的那个设为当前。

### 4. 斜杠命令

```
/plot status               查看当前目标与阶段
/plot add 标题 30          临时加一个 30 楼后的目标（也可写 标题=30、标题@30）
/plot del                  删除当前目标
/plot del 标题或序号        按标题（或 /plot status 里的序号）删除
/plot next                 看下一个目标
/plot done                 当前目标标记完成
/plot delay 20             当前目标再延后 20 楼
/plot now                  当前目标改为立即触发
```

### 5. 悬浮进度条（可拖拽 / 贴边收纳）

聊天界面右下角显示「目标名 · 剩 N 楼 + 进度条」，可折叠，带立即/+10/完成 三个快按钮。
在设置里可关掉。移动端会避让底部安全区。

- **按住拖动**：拖到屏幕任意位置，位置会记住。
- **贴边收纳**：拖到屏幕边缘松手，会变成一条 11px 宽的细条贴在边上（颜色长度就是进度）；鼠标移上去临时展开，移开自动收回；点一下「钉住」就不再自动收；展开时点「浮窗」按钮恢复成普通浮窗。
- **拖动中被中断**（松手在窗口外、页面失焦、按 Esc）会自动回到拖动前的位置，不会卡在「被拖歪」的状态。
- 不想要贴边效果，可在设置里关掉「悬浮条拖到屏幕边缘自动收进去」。

## 参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 注入位置 | 对话中 | 「系统提示词」会弱一些，但更省上下文压力 |
| 注入深度 | 4 | 越小越靠近最新消息、越强势；太大效果变弱 |
| 楼层计数 | 每条消息算一楼（含隐藏楼层） | 与聊天里"共 N 条消息"一致，`/hide` 隐藏的楼层也占一层；也可切「只看可见对话」「只算 AI 回复」 |
| 楼层偏移 | 0 | 对齐你自己的楼层号：当前楼层 = 上面计数 + 偏移。用楼层管理器（从 0 起）就填 -1 |
| 阶段推进曲线 | 缓慢 | 同跨度里多久进入下一阶段：标准 = 线性；缓慢 = 前半段几乎不动（默认）；极慢 = 大跨度时用 |
| 严格程度 | 标准 | 宽松 = 建议式；严格 = 强禁令 |
| 新目标默认跨度 | 40 楼 | 不填目标楼时用 |
| 注入下一个目标的模糊提示 | 开 | 关掉则完全只谈当前目标 |
| 扫描关键词记录伏笔 | 开 | 命中关键词的句子会存下来，注入时提醒「别自相矛盾」 |
| 疑似提前触发提醒 | 开 | 进度还早却在一楼命中 ≥2 个关键词时弹提示 |
| 悬浮条贴边收纳 | 开 | 拖到屏幕边缘松手变细条；鼠标移上去临时展开，点一下钉住。关掉则始终是普通浮窗 |

## 注意事项

- **Token 成本**：每次注入约 200–400 字，随字段多少变化。嫌重就把说明写短、关掉「下一个目标提示」。
- **进度存在聊天里**：删掉聊天/角色卡，目标也没了。重要设定可用「导入 / 导出（JSON）」备份。
- **不动你的正则**：本扩展不写消息文本，和你现有的显示正则、状态栏正则互不干扰。
- **和世界书/预设共存**：注入是独立的一段提示词，不会改你的预设，也不需要重开新档。
- 关键词扫描只对**之后收到的 AI 回复**生效；装好后往回翻的历史不会补扫。

## 版本

- 0.2.7 — 新增「阶段推进曲线」：默认「缓慢」——把线性进度做指数压缩（exp 1.6），40 楼的目标前 13 楼都在起念期、第 25 楼才进浮现期，避免每聊一楼进度就跳一格；另有「标准（线性）」与「极慢（exp 2.2）」可选。HUD、卡片、`/plot status` 显示的百分比同步变慢。
- 0.2.6 — 注入文案重写：不再提任何“推进速度/节奏”，改说**这件事可以怎样出现在场景里、出现到什么程度**（预设里已有负责推进剧情的条目，这里只做伏笔呈现的约束）。阶段名「推进期」改为「浮现期」；新增两条硬约束：与目标无关的楼层是常态、可以连续多楼完全不提；相关角色不因为“该铺垫了”而登场。注入里的「进度第 X 楼 约 N%」改为「位置：目标第 Y 楼（当前第 X 楼）」，去掉百分比。「已出现过的相关片段」改为「不要重复，也不要与之矛盾」。
- 0.2.5 — 「目标楼」输入框下面实时显示**当前楼层**与换算结果（`第 22 楼 = 大约 20 楼后` / `就是现在` / `已经过去了 N 楼`），并加了 4 个快捷按钮「当前+10 / +20 / +40 / 就是现在」；魔棒快捷弹窗里同样有这一行。已切到设置面板或打开「添加剧情目标」时会自动刷新楼层数（避免聊天还没载入时显示 0）。已在 SillyTavern 1.18.0 与 TauriTavern 2.4.0 实测。
- 0.2.4 — 悬浮条可拖拽 + 贴边收纳：拖到屏幕边缘松手自动收成 11px 细条（细条里用颜色长度显示进度），鼠标移上去临时展开、点一下钉住、展开时点「浮窗」恢复；拖到别处则记住位置。拖动被中断（松手在窗口外 / 页面失焦 / Esc）会还原到拖动前的贴边状态，不会卡住。设置里可关掉贴边收纳。已在 SillyTavern 1.18.0 与 TauriTavern 2.4.0 实测（四边贴边、钉住、取消贴边、焦点丢失还原）。
- 0.2.3 — 新增「删除目标」：目标卡片与魔棒快捷弹窗里都能删（点两次确认，防手滑），删掉当前目标会自动把最近的一个设为当前；新增 `/plot del` 斜杠命令。另修好 `/plot add 标题 楼数`——原来写的 `标题 | 楼数` 会被 ST 的管道符吃掉，数字被忽略而悄悄用了默认跨度，现在支持空格、`=`、`@` 分隔。
- 0.2.2 — 修复楼层数识别：以前跳过 `/hide` 隐藏楼层（ST 里是 `is_system` 消息），遇到大量隐藏楼层的聊天会严重少算；现在默认「聊天里有几条消息就是几楼」，另加「只看可见对话」「只算 AI 回复」和楼层偏移。已在 ST 1.18.0（36 条消息 / 25 条隐藏 → 36 楼）与 TauriTavern 2.4.0 验证。
- 0.2.1 — 新增魔棒快捷入口：魔棒菜单「伏笔导演」→ 快捷弹窗（当前目标进度 + 快速添加剧情点 + 打开完整设置）。已在 SillyTavern 1.18.0 与 TauriTavern 2.4.0 实测（菜单项、弹窗、快速添加、跳转完整面板）。
- 0.2.0 — 适配 TauriTavern 2.4.0：模板渲染失败时自动退回直接读取 `settings.html`；
  设置面板宿主容器兜底；移动端悬浮条避让安全区。
  已在 SillyTavern 1.18.0 与 TauriTavern 2.4.0 实测通过（扩展加载、设置面板、悬浮条、斜杠命令 `/plot`、注入项注册）。
- 0.1.0 — 首版：单点目标、大纲批量、五阶段、伏笔扫描、提前触发提醒、悬浮进度条、斜杠命令、JSON 导入导出。
